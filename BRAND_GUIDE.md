# LARI website brand use

This site uses the corrected **LARI Brand Kit v4**. LARI means **Local Autonomous Recursive Intelligence**. The v4 guide supersedes earlier kits for expansion and lockup text.

## Assets copied into this project

- `assets/lari-glyph.svg`: approved master glyph, copied byte-for-byte from v4 `master-glyph/symbol-green-transparent.svg`.
- `assets/lari-primary-light.svg` and `assets/lari-primary-dark.svg`: corrected v4 header/footer lockups.
- `assets/favicon.ico`, `assets/lari-icon-*.png`, and `assets/site.webmanifest`: corrected v4 platform icons.
- `assets/lari-app-icon-dark.svg` and `assets/lari-website-hero.svg` / `.png`: corrected v4 supporting assets.
- `assets/brand-tokens.css` and `assets/brand-tokens.json`: v4 design tokens.

The v4 package documents that the original approved master geometry was retained byte-for-byte, subtitles corrected and sized to fit, and PNG lockups regenerated. This site uses only current v4 assets; it does not use the legacy mockup reference.

## Usage

Retain aspect ratio, preserve the glyph paths, and keep the logo clear space described in the v4 guide. The page uses the light lockup on paper and the dark-background lockup in the footer. Green is an accent; body copy remains in a readable sans-serif and technical labels use monospace.
